# seqtk WebAssembly command

`seqtk.wasm` is the seqtk 1.4 artifact published by Biowasm at
`https://biowasm.com/cdn/v3/seqtk/1.4/seqtk.wasm`. `build.sh` reproducibly
renames the legacy split-i64 `fd_seek` import so it cannot be confused with the
modern Preview 1 ABI. The transformed SHA-256 is pinned in
`corpus/catalog.json`.

The command-style Emscripten build uses WASI for streams and a small `env`
compatibility surface. The workload converts FASTQ supplied on stdin to FASTA;
filesystem syscalls remain denied.

The exact output is generated by the matching published JavaScript glue under
Node/V8 and checked in `build.sh` before the Wago artifact is accepted. Native
seqtk is only a secondary cross-check.
