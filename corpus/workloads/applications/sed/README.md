# GNU sed WebAssembly command

`sed.wasm` is the GNU sed 4.8 artifact published by Biowasm at
`https://biowasm.com/cdn/v3/sed/4.8/sed.wasm`. `build.sh` reproducibly renames
the legacy split-i64 `fd_seek` import so it cannot be confused with the modern
Preview 1 ABI. The transformed SHA-256 is pinned in `corpus/catalog.json`.

The command-style Emscripten build uses WASI for streams and a small `env`
compatibility surface. The corpus host denies filesystem syscalls because this
workload reads stdin and writes stdout only.

The exact output is generated by the matching published JavaScript glue under
Node/V8 and checked in `build.sh` before the Wago artifact is accepted. Native
sed is only a secondary cross-check.
