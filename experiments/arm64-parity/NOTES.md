## Rejected: branch around expensive pure integer select arms

General expression-cost admission; no workload IDs or constants were matched. Excluded memory loads, division, references and effects to preserve Wasm eager evaluation and traps. Froze surviving register owners to prevent spills on only one edge. Correctness and register-allocation tests passed; all 102 application oracles passed.

- Aho-Corasick execution: median 265,868 ns → 87,336 ns (3.04× faster).
- Aho-Corasick compilation: approximately 165 µs → 158 µs; no clear compilation penalty.
- Independent high-entropy conditional arithmetic probe, 65,536 iterations: 147,449 ns → 224,290 ns (about 52% slower).
- Mitigation: raise expression-cost threshold from 6 to 12. This removes the original Aho-Corasick improvement. A longer four-multiply random arm still runs 268,781 ns versus 247,663 ns eager (8.5% slower).
- Decision: discard. The unpredictable-condition execution regression outweighs a gain dependent on sparse conditions. Rejected patch retains the threshold-12 version for review; it is not active compiler code.

The initial full-set candidate run overlapped correctness tests during its first seconds. It is useful for oracle coverage, but its early timing cells are not clean evidence of a compilation regression. Focused measurements above were run separately.

## Retained: next-use admission within bounded control regions

Profiler-guided follow-up: avoid regional leases for values with no further read before the next control edge, rank eviction by the next access within that region, and omit writeback only when an overwrite is proven before the edge. The event index records control boundaries alongside per-local accesses. A taken branch, backedge or diamond therefore cannot inherit a lexical dead-store assumption from another path. Final-read ownership transfers remain disabled for control-flow functions.

Tradeoff and mitigation, three alternating runs per stage:

- Next-use eviction alone: Reed execution 135949 → 134595 ns (1.0% faster), compilation 89480 → 100333 ns (12.1% slower). Insufficient benefit alone.
- Add admission filtering: Reed execution 136981 → 125446 ns (8.4% faster), compilation 92030 → 89309 ns. AES execution 36827 → 38137 ns (3.6% slower), compilation 147078 → 154201 ns (4.8% slower).
- Mitigate by retaining the cheaper score policy where whole-function local pinning is available. Control-region next-use planning applies to wide local tables (>64 locals), matching the existing architecture's whole-function pinning limit. These tables rely on dynamic regional caching rather than permanent GP pins. No workload IDs, constants or artifact checks.
