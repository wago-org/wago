# Executable branch-vector prototype: arm64

Retained default on: `br-table-branch-vector` / `WAGO_ARM64_EXPERIMENT_BR_TABLE_BRANCH_VECTOR=1`. Reuses the existing small unique-table cohort (5–32entries). Both labels and default must target non-function zero-argument control frames; excludes compacted code, lazy call-state reconciliation, EH, custom instructions and tracked GC frames. Index addressing uses ADD X17,X16,Windex,UXTW#2, preserving i32 index semantics. Nearby default branch and one four-byte B per label avoid the old signed-offset load and address addition. Vector entries are opaque to finalizer rewrites so their fixed stride is preserved.

No corpus recognition in production admission. Existing small-unique threshold bounds compile work and avoids duplicating many per-target metadata edges for duplicate-heavy tables; larger/duplicate/argument-carrying/effectful tables retain established lowering.

Independent Clang encodings match new encoder goldens; invalid shift values emit nothing. Native tests verify computed indexes, every small target, reordered labels, in-table/out-of-table defaults, unsigned high indexes, duplicate fallback, both bounds and compact/plain policies, on/off switches and strict diagnostic admission. Full backend/catalog/encoder diagnostics and all46core+102application signal exact oracles pass.
