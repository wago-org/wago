# Dominated indexed base prototype

Prepared only, not integrated/tested. Unlike the rejected eight-instruction straight-line late reuse, this proof admits finalized direct branch diamonds when an earlier exact ADD X16,base,index dominates all paths into the candidate. Inputs and X16 must survive every intervening instruction; entering the seed is allowed, entering after it from outside the bounded window is rejected. Calls, indirect branches, unknown encodings and source modifications invalidate the proof. Every removed ADD becomes NOP; no compaction hole is recorded.

Bounded eligibility: function<=4096bytes,128directedges,64instruction lookback. Edge scratch is fixed/stack allocated, no per-function retained metadata. Branches must be patched before this pass. Initially run only with existing finalizer indirect-branch exclusion.

Required tests: all branch forms, internal forward diamond, outside entry to candidate/middle, backedge bypassing seed, entry exactly at seed, protected register overwrite (bothW/X), nonmatching X16 seed, call/indirect/writeback/unknown invalidation, edge overflow, function/lookback limits, canonicalization changes. Native fixtures must prove on/off checksums across both paths and repeated loop iterations in both bounds modes. Independent decoder goldens must validate each whitelisted write class. Diagnostics plus affected-image scope before focused timings, measure compilation cost; mitigate scan costs if execution benefit is small.

Encoder implementation is a draft standalone method; compiler integration must reject EH/custom instruction streams as well as opaque indirect fragments. All direct incoming branches, including BL, participate in the predecessor check; BL is never accepted as a preserving instruction. Draft diamond and protected-write tests prepared; broader tests/native validation still required.

More than128candidates conservatively disables the pass, so scope/native identity must be compared before any timing interpretation. This draft is not integrated or tested; wait for the original prototype tradeoff before choosing it.
