# Integer select local reads on Apple M4 Max arm64

Retain the narrow **integer-select-local-read** option, default ON. ML-kmeans improves **5.34%** in the final four-pair option comparison (24.781→23.495µs); the actual pristine-source four reversed process pairs confirm **3.93%** (25.306→24.310µs). Polygon clipping improves **5.96% / 6.94%** respectively. Final option compilation is ML +0.83% / clipping −1.80%; actual-source compilation is −2.31% / −2.51%. No full timing sweep was run: only the native-affected cases and focused controls.

[32 affected cases](affected-subset/summary.md), [actual-source comparison](evidence/cross-summary.md), [source raw samples](evidence/cross.jsonl). Source controls ADPCM and DCT have byte-identical images. Their observed timing drift is not credited to this optimization. Document layout and raytrace are changed controls; final affected-repeat execution is −2.04% / +0.09%, with actual-source +0.54% / +1.01%. Bresenham and register allocation repeat at +0.22% / +0.82%. No material execution regression repeated. Initial compile outliers were confirmed separately with eight 150ms pairs and became flat: quickselect +0.70%, CoreMark −0.15%, kissfft +0.31%. [Confirmation](evidence/compile-confirm-summary.md).

The general emitter handles a materialized integer condition followed immediately by local.set/local.tee to a register-resident destination. It protects destination, then condition/B/A reads, retaining physical stack roots until the immediate CMP Wcond,0 / CSEL. It releases only owned temporaries, consumes operands after CSEL, and preserves the existing older-local snapshot realization. The declared destination type sets CSEL width: deferred I64 comparisons can produce I32 results. Existing flags-select lowering is unchanged. The emitter adds constant bookkeeping per sink and reuses existing materialization; no prepass or corpus/argument recognition is introduced. Cached constants and permanent/regional homes remain borrowed. Conventional rollback: WAGO_ARM64_NO_INTEGER_SELECT_LOCAL_READ=1 or per-compile option false. The patch includes its real catalog Definition/Binding and policy fixture, without experimental hooks.
