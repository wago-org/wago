# Equivalent indexed-address facts: arm64 experiment

Retained, default on, dominated-indexed-key. The retained address analysis stored the instruction position of an ADD X16,base,index as its fact. Equivalent definitions at separate predecessor sites did not meet, and an arbitrary 256-byte origin window ended reuse. The new bounded pass tracks the exact physical base/index register pair instead, with the same <=4KiB function, <=128direct-branch and unknown-write/backward-entry/custom/EH restrictions. Facts are invalidated on any protected-register write; only equal pairs meet. Two KiB stack metadata, no heap allocation, unchanged native code size through NOP replacement. No workload recognition.

The initial fixture job found a duplicate copied test name and stopped before the encoder tests; corrected. Full backend/runtime/catalog/encoder diagnostics and all148 exact corpora now pass both bounds modes. Independent diamond fixtures prove equivalent seeds from different definitions merge, different pairs do not; borrowed branch memory and loop/trap fixtures execute on/off. The actual changed inventory contains7apps and13core corpora.

Eight-round 200ms focused timings: image-median exec -4.75% paired, compiler-register-allocation -1.36%, search-horspool -.79%; KNN +1.67%, rabin-karp +1.00%, modular arithmetic +.54%, kissfft +.44%. Other affected app execution is approximately flat. Most compilation changes are small/flat, with noisy coremark. The initial adverse observations required confirmation before retention. Full-corpus parity remains unproven.

Twelve-round 300ms application confirmation gives image-median **-5.98% paired execution** (IQR -8.34% to -2.54%, pooled -5.24%) with **-.34% compilation**. Register allocation is flat (+.08% execution/-.39% compile). KNN changes -1.09% paired execution but -.05% pooled, so no KNN gain is claimed; compile +1.22% is a small tradeoff. Rabin-Karp is flat (+.01% execution/+.67% compile). Eight-round affected-core confirmation gives modular arithmetic -.20%, kissfft +.34%, PCRE2 +.57%, nbody +.06%, raytrace +.05% execution, with mostly flat compilation; kissfft compile is noisy (+1.99%, wide IQR). Earlier apparent KNN and Rabin-Karp execution regressions did not repeat. Retain the general exact-key pass for the repeatable median-filter gain and mostly flat costs.

The exact-key representation also removes repeated seed-word reads and the arbitrary origin-age restriction without increasing the metadata footprint. No corpus identity, memory layout or data-dependent heuristic enters admission. All148 both-mode oracles and diagnostics passed the measured implementation. The default-state combined qualification will follow the parallel candidate imports. Rollback: dominated-indexed-key=false or WAGO_ARM64_NO_DOMINATED_INDEXED_KEY=1.
