# Ranked LibTomMath motifs after initial-zero rejection

Read-only investigation of `profile-next-20261011-libtommath-assembly.txt`. Its manifest records37174169 on Apple M4 Max, signals; native proof records the exact93588-byte qualified image. Later guarded-boolean-xor/taken-zero-branch/selector changes may move offsets. Sample observations locate regions; they are not instruction-time weights. Compiler admission must use actual operands and structure, never this workload's identity.

1. **Immediate selected private-local read reuse for a flags comparison.** f28 at6678/667c loads `[SP,#0x48]` twice: selected value intoX10, comparison RHS intoX11; `CMP W24,W11; CSEL W9,W10,W9,GE`. Wasm confirms `local.get9; local.get4; local.get9; i32.lt_s; select; local.tee6`. A selected source that is still a concrete `stLocalRef` names the current private local version; older snapshots are realized before a write and cannot enter this case. Materialize/pin the selected branches in the existing order, then loan that protected selected register to an exactly matching direct comparison leaf. Comparison type and leaf storage identity must match; the original compare width and result ownership remain unchanged. Consume the loan with the comparison before CSEL. No function fields, traversal, persistent cache, borrowed result or memory/trap movement. Predicted signal: one fewer LDR and comparison temporary at this motif; compiler latency approximately flat. Division's `integer-select-local-read` changes materialized-condition local sinks and leaves this flags/stack-result path untouched. This is the chosen first prototype.

2. **Literal memory32 index folded into shifted displacement.** f19 at3fb8..3fc8 materializes0x102bc withMOVZ/MOVK and performs an indexedLDR. A shifted-page ADD from the linear-memory base plus a scaled low-offset LDR can take two words instead of three. The retained encoder already handles split memarg displacement, but `memAddr` materializes the literal index before passing it onward. Admission needs an actual constant index, overflow-safe address+memarg+width arithmetic, preserved original bounds/trap ordering and a word-count comparison that respects an already cached constant. Deferred memory references currently own/borrow an address register; using ZR or eagerly loading needs an explicit ownership/lifetime proof. Do not add a magic address/layout check. Predicted signal: fewer constant materializations/transient address registers for uncached static accesses; no extra body analysis.

3. **Full-width unsigned vector dot reduction with reversed affine streams.** f28 at6740..6770 performs four LDRW and two serial `MADD X13,...,X20; MADD X20,...,X13`; source confirms two `i64.load32_u` products plus the i64 accumulator. One stream advances8 bytes, the other retreats8; a2-step counter ends the loop. UMULL/UMULL2 plus64-bit vector ADD can retain every32x32 product and modular64-bit sum, avoiding the existing pure-reduction requirement that each product fit32 bits. Reversed lane order needs a shuffle. Require a call-free read-only kernel, empty entry stack, bounded register preflight, exact dynamic trip/induction proof, full widened memory ranges and no intermediate i32 address wrap. Any guard failure must execute the original scalar body; restore every modified local and scalar tails exactly. Existing `dot_loop.go` only admits i32 locals/arithmetic and both existing reduction emitters exclude `usesCalls`, so this call-making outer function needs a separately proven inner region rather than removing the exclusion wholesale. Highest possible payoff, substantially larger correctness and compiler-budget exposure.

f51's hot subtraction/borrow chain already folds a prior `>>31` into ADD's shifted operand, and f4's backward scan already uses one indexed load and an immediate pointer decrement. ADC/SBC carry substitution is not presently justified: a raw32-bit load is not proven to be a28-bit limb, and `(a-b)>>31` is not a general unsigned-borrow predicate. Neither source/library semantics nor masked stores elsewhere establish that range for arbitrary Wasm inputs. Native-pointer/post-index induction lifting would likewise require nonwrapping/full-range guards and exact final local reconstruction; it is not chosen ahead of the lower-cost plans above.

No initial-zero retry. Rejected source/evidence archives are in main `experiments/rejected-entry-dead-zeros/` and `experiments/rejected-dead-index-home/`.
