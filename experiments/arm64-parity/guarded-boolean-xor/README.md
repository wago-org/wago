# Guarded integer boolean XOR

Apple M4 Max, arm64; source baseline `37174169`, all five prior retained options enabled. Retain the general `guarded-boolean-xor` optimization default on. Disable it with the per-compilation optimization option or `WAGO_ARM64_NO_GUARDED_BOOLEAN_XOR=1`.

Four reversed-process 100ms pairs against the actual pristine source compiler confirm **point-in-polygon execution -4.10% paired / -3.80% pooled**. Compilation increases **+6.40% / +6.43%**, about **2.13µs** (33.10→35.23µs). Roughly three invocations amortize that cost. Two small control workloads show possible unconditional compilation costs: ADPCM +1.20% paired / +1.87% pooled, glob +1.78% / +1.33%; register allocation and DCT compile essentially flat. Their native images are unchanged, and no execution gain is claimed for them. [Cross-build table](cross-summary.md), [raw samples](cross-build.jsonl).

An independent eight alternating 150ms option pairs improve polygon execution -4.75% paired / -4.31% pooled. The first unmitigated scan caused approximately 1–2% compile costs on several unaffected workloads. A candidate preflight inside the existing branch-target scan avoids another full walk when no bounded comparison/CSET/XOR tail exists; queued CFG states avoid repeatedly walking matching joins. The final option comparison leaves the unaffected compilation controls flat within this screen, while polygon compilation remains approximately +7%. [Execution samples](guarded-xor-memo-exec.jsonl), [compilation samples](guarded-xor-memo-compile.jsonl).

Of 148 qualified signal-mode native images, **147 are byte-identical to the baseline**. Only polygon changes, retaining its **640-byte** image and layout: native `+0x188` changes `B.LO` to `NOP`, and `+0x1ac` changes `CMP W11,W12` to `CCMP W11,W12,#1,HS`. The original integer range guard's flags gate the final crossing predicate; the fallback flags make the XOR input zero outside the guarded region. Final default-on emission without an experimental environment hook exactly matches the measured enabled image. [Image proof](native-proof.txt), [default-on proof](default-on-proof.txt).

Admission recognizes native instruction structure, with no corpus identity or manifest arguments. The region is bounded to a short pure integer body: memory, calls, division, unknown encodings, SP forms, flags readers/writers, exception/custom instructions, and interior branch/native entries decline. Only scratch registers may be speculatively overwritten. A bounded direct-CFG proof follows at most 64 branch states and 512 instructions, proving full scratch changes dead and tracking the newly cleared high half of W XOR outputs through MOV X copies until overwritten or proved outside the return ABI. Full-width observations decline. The normal pin-preserving call ABI remains respected.

All 148 exact contracts pass in **both signal and explicit bounds modes**. Final signal images match the earlier qualified candidate byte for byte.
