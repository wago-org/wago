# Concrete read-only standalone multiplication: arm64

Default off, option `borrowed-mul`, environment `WAGO_ARM64_EXPERIMENT_BORROWED_MUL=1`. Uses MUL with an independent result register and a pinned source directly, eliminating an otherwise redundant MOV. Both operands must be concrete; left must be a pinned local/global and right a constant or register. Existing strength reductions and destination-directed paths take precedence. No corpus recognition.

Diagnostic source preservation, same-source alias, old-local snapshot, destination alias, unsigned wraparound and both-width/bounds tests pass. The first fixture used a destination-directed chain and correctly did not admit this cover; it was corrected to force standalone consumption and now verifies admission. Full backend/catalog/encoder diagnostics and all148 signal exact oracles pass. Eleven core and22 application native images change. Focused timings cover polygon, Gini, DCT, optical flow, skinning, Aho and core modular arithmetic. Explicit-bounds qualification is queued. No retention decision yet.

First focused pairs (8round200ms): polygon execution +1.84%, skinning +1.51%, DCT +0.56%, optical flow -1.19%, Gini -0.34%, Aho -0.34%, core modular arithmetic -0.58%. Compilation roughly flat (-1.15% to+0.53%). All148 explicit oracles and ordinary backend tests pass. Gains do not presently justify retention. Before rejection, layout mitigation replaces each eliminated MOV with NOP; three selected images match baseline size and only MOV/NOP and multiply source fields differ. Diagnostics and all148 signal oracles pass; longer focused confirmation is queued. Default remains off.

Rejected after layout mitigation: longer12round300ms execution polygon -0.56%, skinning -0.33%, optical flow -0.09%, core modular arithmetic -0.01%; compilation -0.49% to+0.60%. Avoiding layout movement cures initial regressions, but repeating the same instruction footprint leaves no meaningful benefit. Production cover, option and tests removed; reproducible sources and integration patch archived in experiments/rejected-borrowed-mul. Rollback verification queued.
