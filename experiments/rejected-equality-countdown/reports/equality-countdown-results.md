# Modular equality countdown on Apple M4 Max

**Decision: reject this candidate entirely for production this hour.** It has a reproducible LCS win, but a reproducible edit-distance regression and measurable compiler cost. The archived source patch is a general ARM64 experiment named `equality-countdown`; no live source, hook or catalog entry was imported. The production source patch is `../patches/equality-countdown.patch`; the isolated worktree starts at `c74d21c1`. It requires a loop counter that the body cannot observe. The broader used-counter variant was rejected after measuring its compiler cost and mostly flat execution results.

The reproducible execution gain is LCS: **-5.71%** median paired time over twelve alternating 300ms pairs, IQR -6.32% to -5.25%. Compilation is +2.66%. A preceding eight-pair restricted measurement was -5.99%. Grid's first -3.17% did not repeat (twelve-pair result -.19%), so no grid execution gain is claimed. Unchanged polygon is flat for both execution and compilation. [Final confirmation](../reports/equality-countdown-restricted-confirm-summary.md) retains raw paired results and intervals.

The final signal-bounds exact oracles pass all 148 corpora (102 applications, 46 core contracts). Full ARM64 backend, catalog and encoder diagnostics pass, including strict fixtures in both explicit and signal bounds modes. The earlier unrestricted CBNZ form also passed all 148 exact oracles in both bounds modes; the final form only removes admissions and preserves its admitted native emission. Integrated explicit-bounds qualification belongs to the root's combined import check.

Final native inventory changes **29 application images and three core images** (fast_float, YYJSON, zlib). [Complete inventory](../raw/equality-countdown-restricted-native-changes.txt) gives old/new sizes. RLE, Kmer, median image filter, dilation and spatial hash are byte-identical off/on; timing drift in those controls is not an execution regression or gain from this feature.

## Proof and code

A bounded decoded scan proves the sole backedge is `bound != (counter += positive_constant)`. Counter and bound are distinct i32 locals with existing permanent integer register homes. The counter is read only by the latch and written only there; the bound is invariant. The scan declines escaping branches, alternate backedges, nested loops, calls, interruptible polls, EH/custom instructions, tracked roots, older operands at loop entry, regional control leases and existing vector-loop joins. Fixed limits are 64 locals, 256 instructions and 1024 bytes. No workload identity, manifest argument or expected result is consulted by production code.

Initialize the counter home with `bound-counter (mod 2^32)`. Replace the three-instruction ADD/CMP/B.NE latch with SUB/CBNZ; restore the exact original final counter from the unchanged bound on fall-through. For every starting value and admitted step, subtracting the step from this distance is zero exactly when the original updated counter equals the bound. This preserves unsigned-high values, wrap, nonterminating congruence classes and do-while behavior when the initial counter equals the bound. No iteration is removed or moved across an observable effect.

Native fixtures independently check returned values and both original post-loop locals across compact/noncompact code, both bounds modes, wrapping starts, step 1/2/4095 and internal forward branches. An immediate division trap with initial counter equal to bound proves first-iteration trap order. Live-counter, alternate-backedge, zero-step, interruptible and older-operand cases decline.

Compiler cost is controlled by canonical suffix, existing-pin and second-read rejection filters before the decoded proof, a six-entry ring and four 64-bit once/twice read/write masks. Raw-byte filters only decline; complete decoded proof establishes every admission. The final pin-preflight eight-pair compiler screen was LCS +3.55%, grid +2.15%, dilation +1.55%, spatial +2.21%, merkle +2.89%, polygon -.36%. These costs are still measurable. [Cost mitigation](../reports/equality-countdown-pin-preflight-summary.md).

## Profiler evidence

Prepared, exact-oracle LCS captures use the repository profiler, Samply at requested 1000Hz for three seconds, signal bounds, native code and Wasm source maps. The hot DP loop instructions and native offsets +0x240..+0x290 are unchanged. The row-copy loop changes ADD counter,#4; CMP; B.NE into SUB counter,#4; CBNZ, then a restoring MOV. Copy-region leaf observations are roughly 8–10% in both captures; observations are not CPU-time weights. The entry conversion also shifts the copy-loop fetch alignment by 16 bytes, so the measured whole-workload gain can include layout effects.

[Off assembly](../raw/profile-equality-countdown-lcs-0-assembly.txt), [on assembly](../raw/profile-equality-countdown-lcs-1-assembly.txt). Capture manifests retain exact module/contract hashes, image/source maps, collector version, phases, iterations and device metadata.

## Final subset and compiler costs

The 29-application affected-image screen completed with four alternating 100ms pairs per phase. Median paired execution delta is -0.11%; median compilation delta is +2.76%. Its provisional protobuf -5.23% did not repeat in eight 200ms pairs (+.09%, flat). **Edit-distance regresses +2.56%** in confirmation (IQR +2.36% to +2.90%) with +3.47% compilation. B-tree is noisy (+1.69%, IQR -.34% to +7.04%, pooled medians flat); page-packing is flat. [Full affected screen](../reports/equality-countdown-restricted-screen-summary.md), [confirmed tradeoffs and core results](../reports/equality-countdown-restricted-followup-summary.md).

All three changed core compiler cases completed: fast_float +.11%, YYJSON +.29%, zlib +.87% (wide IQR for zlib). Fast_float execution +.48%, YYJSON -.08%; no core execution gain is claimed. The first attempted core timing invocation accidentally used the application manifest; its raw failed log is retained, and it contributed no result. The corrected job uses the corpus cache and proper workload basenames.

A final layout mitigation places the entry conversion inside the existing four-NOP small-loop phase padding, preserving original hot-loop headers and image sizes. Strict fixtures pass. LCS retains -5.34%, but edit-distance worsens to +3.57% (IQR +2.95% to +4.26%). This does not cure the general tradeoff and was reverted. [Rejected padding mitigation](../reports/equality-countdown-padding-summary.md).

Eight alternating independent-process comparisons against the pristine `c74d21c1` compiler with equality-countdown disabled give LCS +.35%, register allocation +.56%, grid -.58%, polygon +1.27%. Both binaries use the existing regional-memory-read option disabled, identical original policy defaults, guardpage tags and requested QoS33. Each process locks its OS thread; this does not establish physical-core affinity. These controls are mostly small/noisy, but polygon's positive IQR means zero unconditional compiler cost is not established. [Pristine source-off controls](../reports/equality-countdown-offcost-summary.md).

The minimal mandatory-dead-counter source is restored byte-for-byte to the already-qualified version. It remains defaultoff. Broad use would impose ~2.75% compiler cost on this affected set and a confirmed edit-distance execution regression despite the LCS win. Production main sources were never edited by this experiment. Every heavy build, diagnostic test, oracle, timing and profiler capture uses `~/benchmark-lock.py --wait --owner wago-counted-loop`; each reservation is short and shared-device waiters are polled.

[Earlier rejected forms and wider screens](../reports/equality-countdown-investigation.md) preserve the investigation and timing noise without attributing their gains to the final restricted candidate.
