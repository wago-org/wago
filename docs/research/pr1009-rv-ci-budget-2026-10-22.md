# PR 1009: separate native RV64 qualification builds

The [cancelled native job](https://github.com/wago-org/wago/actions/runs/39839450493/job/120052879201)
on `9efe8d8fe0aa7051dc8f3c1aa220c5367d8f3395` exceeded its 90-minute job
limit. The check annotation explicitly reports that limit. This is a budget
cancellation, not an observed failing JIT test. Smoke, CLI, backend/runtime,
ordinary public tests and ordinary artifact loading completed. The checked
public set also passed; its package body took 513.432 seconds. The last package
pass was 21:10:16 UTC. Cancellation at 21:37:58 left Go and compiler processes
for cleanup. Guard-page checks had not started.

## Change

The old job combined every native build variant under one timer. Give each
large Wago test variant a separate native RISE job: ordinary public preparation,
checked public preparation, ordinary compiler-free loading, checked compiler-free
loading, ordinary guards and checked guards. Core backend/runtime and CLI checks
have their own job. Keep the exact single RISE runner label, pinned tools,
`-gcflags=-c=1` workaround, per-test limits and 90-minute native job limits.
Run at most two native jobs at a time in each dependent matrix. The final
five-minute status job retains `JIT / native Linux RISC-V64` and requires every
native matrix to succeed. Failures, cancellations and skipped prerequisites
produce a visible failure rather than a false pass.

The script defaults still run both ordinary/checked builds and interleaved
prepare/load checks locally. CI can select one check and phase. Explicit
artifact directories survive the preparer and must exist for loading. The
workflow transfers complete per-check guest artifact directories within the
same workflow run. Load commands retain `wago_precompiled`; artifact loading
still runs in a separate executable with no compiler. No test selector,
assertion, Go test timeout, guest runtime or artifact codec changes.

## Evidence and limits

The routing regression fails against the old script because a requested
preparation phase does not retain its artifacts. The repaired script passes.
A recording Go executable confirms that split phases run the multiset of old
commands exactly once: 14 public commands, 12 artifact-only commands and both
guard commands. Compare arguments and all artifact directory/mode settings,
including the immutable parent script from Git. Simulated artifact transfer
copies the prepared files and removes the original directory before loading.
Test failures stop immediately. Invalid selectors and missing artifacts fail
visibly. The real final workflow gate rejects every failure/cancel/skip pair.

A real QEMU test prepares 24 portable feature artifacts, copies them to a new
directory, removes the source directory and loads/executes every case with
`wago_precompiled`. This covers the actual handoff beyond the recording stub.
An initial manual invocation missed the output directory; its failure remains
in evidence and the corrected preparation/load runs pass. An early harness
assertion inspected the command's first argument instead of its tags argument;
that harness error and its corrected pass are retained separately.

QEMU proves behavior, not native timing. These changes distribute compilation
work; they do not claim to make the Go compiler faster or fix its internal
DWARF issue. The next hosted native run must establish the new job wall times.
The full native matrix is not claimed passed locally. Compiler activities over
30 seconds remain budget faults, including the saved cold QEMU test builds.
Measurements, validation results and a compact cancellation excerpt follow in
the accompanying evidence directory. The full hosted log remains saved at
`/tmp/wago-pr1009-rv-cancel-20261022-evidence/native-job.log`.
