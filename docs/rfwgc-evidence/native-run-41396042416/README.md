## Diagnosis and minimal parent repair paths

1. **Verified production compile failure: ARM64 dynamic import local-state join.**
   `src/core/compiler/backend/railshot/arm64/call.go:1883` returns
   `direct Go import local-state join differs at local 0` when the emitted Go-host
   alternative and cross-instance alternative disagree about a local's state.
   The pinned `emitDynamicHostOrCrossInstance` takes `locals`, emits
   `callHostSync`, optionally restores preserved pins, saves `fastLocals`, then
   resets the original locals and emits `emitCrossInstanceCall` before comparing.
   This is a production compiler error on valid imports, not a download/setup
   failure or the old graph-option error. It affects `examples/23-public-api`,
   ordinary host/native-alias tests, sqlite3/qjs/jq compilation, and linking
   assertions in proposal/Core 2/Core 3 suites, in all modes.
   Parent should minimize `TestExample` or the linking provider and reconcile
   actual spill/reload transitions across those two alternatives in `call.go`,
   `localstate.go` and, if necessary, the `compile.go` preservation decision.
   Keep the join check: removing it or rewriting the test to accept the compiler
   error is not a repair. The exact offending state pair is not printed by this
   run; the specific spill/reload patch still needs reproduction/validation.

2. **Verified production error-classification defect at the pinned source.**
   `TestLocalExternrefGlobalsRespectFeatureStoreAndLifetimeBoundaries/forged`
   and `/cross-runtime` report unsupported converted publication where invalid
   externref token is required. Pinned
   `src/wago/gc_conversion_store_other.go:setConversionGlobalPublic` calls
   `unsupportedConversionWord` before ordinary global authentication can classify
   an invalid token. Parent's minimal repair is to authenticate public ingress
   first and delegate invalid words to ordinary validation, while still rejecting
   authenticated converted ownership wrappers. This is precisely the area of
   later commit `c786a9b84bb0298d5bbd6b9522ab611193440cfa`; **that commit is absent
   from this execution source**. These results neither test that fix nor qualify
   any latest head. Do not reapply it blindly or waive a fresh exact-source run.

3. **Verified unit-fixture assumptions, not evidence of a zero-capacity runtime.**

   `TestBulkPhysicalArgumentSlots/externref.fill` create bare ARM64 `fn` values
