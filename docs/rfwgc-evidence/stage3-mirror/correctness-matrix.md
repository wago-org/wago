# Correctness and evidence matrix

All rows below are required implementation qualification, **not completed tests**
of the new collector. Run each applicable row ordinary, wagodebug and
wago_regalloccheck; record explicit unsupported/fallback/skipped outcomes. Native
package tests alone do not exercise emitted-code register allocation. The five
existing-contract tests run by this worker are listed in README.md and do not
close these rows.

For R, a minimum 20,000-cycle deterministic bounded-heap fixture is a useful
regression candidate because it exceeds the owner-reported horizon. It is a
correctness stress test with occupancy assertions, not a benchmark and not proof
that the source symptom exists in Wago. Use smaller rapid variants per slice and
a full-length final gate. Include a finite maximum-live-byte bound in the fixture
so legitimate heap growth is distinguishable from reservation leakage.

No verified new defect is asserted by this matrix. If any row reveals one,
perform a fresh read-only Slipstream and Starshine cross-check before triage,
record affected identities and expected/actual behavior, and keep unrelated
parked Wago GC PRs excluded from the fix.
