Registration resolves actual callbacks/signatures into indexed bindings. There is no general per-call `reflect.Call` or per-scalar interface boxing to remove. The generic inline-frame loop copies P u64 inputs, clears R result slots and copies R outputs back, plus parking/resuming. Scalar and borrowed-view lanes already remove those copies where admitted. Reference and Caller paths retain token/authority/owner and GC protocols. Native arithmetic leaves already bypass Go after instruction-level proof; public function names and numeric signatures alone confer no such authority.

## Safety contract adaptation

Use Wago's actual u64 slots, control frames, owner/root separation, native execution/GC lease protocol and unwind path. Do not port Slipstream's 16-byte carrier layout, result-span fix or collector cursor offsets. Eligibility must prove actual resolved implementation and exact signature; retain public author behavior and plugin revocation. Failed admission/guards must leave dispatch unchanged or roll back all acquired mappings before generic execution. Addressable references/table/tail/reexports may retain their checked generic route. Any native leaf flag must disable bounded-Go-segment assumptions; preserve cancellation and guest scheduling. Diagnostic/profile modes must select their existing conservative paths.

Per-candidate tests must prove the fast route executes and compare forced-generic outcomes, raw slots/high halves, traps, callback effects and relevant state. Include identity/type rejection, mixed callbacks, direct/indirect/ref/tail/cross-instance, cache sharing/close/rollback and mode gates. No speedup claim follows from fewer source operations.

## Baseline evidence

On Linux amd64, Go 1.27.1, a focused eight-test selection passed in ordinary, `wagodebug` and `wago_regalloccheck` modes. The selection covers callback stack growth/GC/trap recovery, wide HostCall view recovery, blocking callbacks, typed i32 stack/GC and blocking, table calls, bad-signature rejection and foreign-owner dispatch. This is baseline evidence, not candidate qualification or full CI coverage. The exact command and logs will be retained in the final evidence record.

Documentation edits cannot alter runtime performance. Candidate changes, if admitted, finish READY TO MEASURE with no timings.
