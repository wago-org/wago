# Fixed-shared native entry-guard experiment

This private source starts at measured/retained `0666c2e3`. It admits one scalar import in a defined, fixed shared memory32 module through the existing bounded-integer-body proof and immutable native tag. The ordinary Go/foreign body remains complete; the native body retains an actual BLR to the validated callback and all guest memory accesses. Profiling, growable/multiple/imported memories, tables/tags/GC roots, unsupported types and unbounded/internal-call bodies retain their existing path.

The earlier `07c2c062` experiment is historical contrary evidence, not a retained optimization. Simply re-enabling its guard in the current source did not help: current shared calls route through emitCrossInstanceCall, while the native-only emitter was reachable only through emitDynamicHostOrCrossInstance. A result-register A/B image assertion exposed this unexecuted optimization. The current experiment shares one native-only emitter between both routes, reachable exclusively inside the entry-guarded body. It optionally retains the i32 result in X0 for the next arithmetic operation, avoiding a stack store/load round trip.

`WAGO_ARM64_SHARED_IMPORT_VARIANT=0` disables only the new shared admission. `WAGO_ARM64_SHARED_IMPORT_RESULT_REG=0` retains stack-result staging in the guarded shared body. Existing native import/cache policies and profiling exclusion still apply. Pure functions remain actual calls; no identity-result substitution or memory forwarding is included.

Focused source/artifact/native/Go/foreign checks include callback counts, full-width result arithmetic and cancellation/GC. Broad ordinary/checker/profiling validation and exact frozen SDK contracts are required before retention. Quick paired probes show substantial native variability, so they are diagnostic rather than publication evidence. The local site and PR remain measured source0666 until independent SDK results, full performance/compatibility, image audit and outlier review justify an update.
