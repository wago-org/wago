# Retained direct Go fallback for fixed shared loops

Main `57105002` and `c4efb91b` retain measured source `191b7ceb`. The fixed shared-memory32 import-only proof already established by dispatch caching allows an ordinary Go import to write its argument and index/shape into the root host-control frame and enter the existing full Go trampoline directly. This bypasses module-context wrapper setup. The native-leaf branch keeps its original fast instruction sequence; unsupported bindings retain the cross-instance fallback. The original Go function still runs, with rooted ownership, native mutex parking, cancellation, traps and panic cleanup unchanged.

The selector requires the existing `direct-go-host-import` policy, cached-dispatch proof, shared memory zero, a sole numeric i32-to-i32 import and no GC frame roots. The scope excludes other memories, growable bounds, globals, tables, foreign guest calls, helpers and custom effects through the underlying proof. `WAGO_ARM64_FIXED_SHARED_GOCALL=0` restores the previous lowering. A new policy test failed before the guard was added and passes after it.

The initial public same-binary owned-callback probe measured opaque 0.6905, ordinary thread 0.9419 and compact 1.0107 versus its control. Actual SDK reversed outlier checks on the final source repeat opaque 0.6773/0.6725 versus retained `435c5202`, about a 32% improvement; compact ordinary is 1.0058/0.9987. Ordinary thread identity is mixed, 1.0343/0.9643. Its native fast sequence remains unchanged, but code layout moves, so do not claim a universal native win.

Full 266-workload outcomes are unchanged. Full steady geometric ratio is 0.99712, compile 1.00739, compile RSS 1.00414 versus `435c5202`; these are descriptive aggregate movements. Only the two thread host profiles change guest images, from 880 to 944 bytes. All other 253 images match `435c5202`. All 255 default images of policy-fixed `191b7ceb` match the earlier `ddb620af` prototype. Main `c4efb91b` has exactly the same 3,109 tracked Go/assembly inputs as the measured source.

Validation includes source/artifact callbacks, original Go callback counts, owned references logically closed after binding, Go stack growth/GC, panic recovery, context-version restoration, Caller validity/expiry with GC, native register-entry preservation and compiler policy rollback. The broader run passes 1,761 test cases but reproduces an existing cross-instance Caller resolver deadline failure on the retained baseline. A shared-instance Caller self-reentry timeout also reproduces with this optimization disabled, on the threaded invocation mutex. Local repro logs preserve both baseline issues independently.

Outliers remain explicit: ordinary-thread compile repeats 1.2094/1.0742; image-median compile previously repeated a one-order 1.1371; final vision-sobel compile is 1.0233/1.4471. PCRE2 steady was 1.1082/1.1341 on the first prototype pass, then 0.9831/1.0741 on the policy-fixed pass; its guest image never changed. Do not dismiss these contradictory timings or attribute unrelated improvements to a two-profile code change.
