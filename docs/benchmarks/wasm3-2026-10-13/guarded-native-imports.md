# Guarded native import loops on ARM64

`7a92edde` retains an entry-guarded native body for bounded integer loops whose scalar imports all declare the same module, name, and type. This is an incremental comparison against retained branch head `9a325a57`, not default main. [The audit](guarded-native-imports.json) includes every full-pass outcome, exact-contract deltas, capture hashes, code-image hashes, and contrary rechecks.

The runtime native-leaf tag selects the specialized body once at function entry. Import aliases resolve to one immutable binding and the instance retains its owner. Every original callback call still executes the admitted native body with its actual arguments. The complete ordinary body handles Go callbacks, foreign Wasm functions, and artifact bindings. The `native-leaf-host` and register-ABI policies, profiling exclusion, checked branch ranges, and environment rollback remain effective.

Only three of 255 inspectable images change; the other 252 are byte-identical. Disabling the variant restores all 255 baseline images. The aggregate compile/RSS figures are controls, not claims of a new compilation optimization. The target pays an extra small body and compilation work for its execution gain.

The largest full-pass timing outlier, `many_funcs`, changes direction in the first recheck and is flat in the reverse recheck. Other contrary evidence remains: `polybench-trisolv` is 2.7% and 2.2% slower in the two rechecks, despite identical generated bytes, and GCD changes direction. This is a targeted retention decision, not a claim of regression freedom or overall feature parity.

The complete ARM64 compatibility sweep remains **346 passed, 27 unsupported, zero failed** across 373 contracts. Ordinary and checker backend/public suites pass; focused diagnostics pass. New tests exercise source versus artifact admission, one/two-argument aliases, exact Go callback counts, owned-reference closure, compact code, policy rollback, foreign Wasm fallback, traps, cancellation, and GC progress. The selector assertion fails against the baseline and passes with the retained implementation.

Argument forwarding and target caching alone did not produce repeatable gains. A subsequent fixed-shared/single-import extension is also rejected: its same-process ratios are **1.054x / 0.974x** across construction orders. It is not part of the retained code. Threads and opaque Go callback parity remain open.

The measured source snapshot and its full compatibility/performance results are kept local. No production deployment.
