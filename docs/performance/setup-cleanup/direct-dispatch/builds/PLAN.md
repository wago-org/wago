# Direct dispatch verification plan

Baseline: Wago 3c56233591dee5e325f7c24b86f665e6107eae96 and provider 08cbb5523586427f060a5b0b422239aadc19448d. Both include the existing snapshot and provider construction fixes. The candidate changes only private handler dispatch in an overlay. Go 1.27.1, Linux amd64, guarded memory/signals, GOMAXPROCS16, CPUs0-15, GOGC100, GOMEMLIMIT off. No race/profile timing runs.

Cause: escape analysis places the callback's 224-byte Plugin copy on the heap at the indirect handler function call. Direct dispatch permits escape analysis to keep that copy on the stack. Pilot counts fell 288B/2 allocs to64B/1 alloc per host call. Pilot timing is exploratory, not acceptance.

Final selection, before collection: 20 new matched process pairs, alternating AB/BA, unchanged focused/phases/host-owned cases. Primary latency controls are direct single and1024 host calls plus complete cjson/tinyxml2 commands. Keep only if the host slowdown is removed and construction/full-command controls do not regress. Also run the three-module/two-API normal/GC/scavenge fixed-work matrix, 20 pairs each, and bounded equal epochs. Physical memory and live heap must not show a material regression. Compare any retained change against the original provider base in a separate20-pair host control, not a cross-session subtraction. Tests must pass on Go1.22.12 and1.27.1, including provider race/lifecycle/isolation and handler mapping checks. Do not pool samples, extend sample counts for significance, or retain the patch on pilot evidence alone.

Separate confirmation selected after the first complete memory matrix: minimal/raw normal released HeapAlloc fell219,376B (95% paired interval -329,842 to-116,911B), and minimal/provider fell218,478B (-220,016 to-217,001B). Run exactly20 new matched pairs of minimal-wasi, both APIs, ordinary memory only, after the epoch run and diagnostic profiles; do not combine these samples with the first matrix. RSS was not significantly reduced, and this confirmation must not be used to claim a general RSS reduction.
