The guest path is an owned Go string from checked guestBytes. pathEscapes only reads it and retains no substring. resolve still checks the descriptor and directory before the path, rejects empty/absolute paths before the scan, and calls path.Clean only after the same depth rule. openAt and all capability/symlink enforcement are unchanged. Scan work is linear in input size; no component slice, unsafe alias, new limit or shared state is introduced. Invalid pointers remain checked with uint64 arithmetic before the guest string is read.
